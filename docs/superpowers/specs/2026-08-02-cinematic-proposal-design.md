# 여운형 시네마틱 프로포즈 설계

## 목표

화면 안의 이야기를 실제 청혼으로 자연스럽게 연결한다. 연출은 감동적이고 절제된 영화 톤을 유지하며, 마지막에 상대가 고개를 들었을 때 반지와 꽃다발을 든 제안자를 보게 한다.

## 사용자 경험 흐름

1. 인트로와 프롤로그는 현재의 어두운 시네마틱 분위기를 유지한다.
2. 촛불을 끈 뒤 추억 장면을 시작한다.
3. 다섯 장의 사진은 모두 같은 전환을 반복하지 않는다. 각 사진은 한 줄의 짧은 문구와 함께 서로 다른 프레이밍 또는 움직임으로 나타난다.
4. 마지막 추억이 사라지면 별빛이 희미한 어두운 배경만 남긴다.
5. 마지막 편지 문구를 순서대로 보여준다.
   - "너와 함께한 모든 순간이 / 내가 가장 아끼는 장면이 되었어."
   - "이제 화면 속 이야기는 여기까지야. / 우리의 진짜 이야기는, 지금부터 시작이야."
   - "고개를 들어 / 나를 봐줄래?"
6. 마지막 문구 뒤에는 2초간 화면 효과와 추가 텍스트 없이 정적을 둔다. 이때 실제 제안자가 반지와 꽃다발을 들고 청혼한다.

## 시각·음향 원칙

- 검정, 따뜻한 금빛(`#e5a872`), 희미한 별빛을 중심으로 한다.
- 화면의 장식 효과는 최소화한다. 꽃 파티클, 과도한 색 변화, 빠른 전환을 사용하지 않는다.
- 사진은 느린 줌 또는 부드러운 페이드로 움직이며, 사진당 문구는 최대 두 줄이다.
- 마지막 청혼 전에는 `Yes / No` 같은 화면 내 선택지를 사용하지 않는다.
- 배경 음악은 마지막 두 문장 전에 낮아지고, 마지막 문구 뒤 정적 구간에서 화면이 실제 청혼을 방해하지 않게 한다.

## 구현 경계

- `index.html`: 청혼 화면에서 선택 버튼을 제거하고, 마지막 편지용 정적 구조를 둔다.
- `script.js`: 화면별 타입라이팅을 실제로 실행하고, 추억별 전환 변주와 마지막 정적 타이밍을 제어한다.
- `style.css`: 별빛 중심의 마지막 장면과 사진별 연출 클래스를 정의한다.

## 완료 기준

- 모든 타입라이팅 문구가 해당 화면 전환 후 정상적으로 보인다.
- 추억 장면이 사진과 짧은 문구의 서로 다른 시각적 리듬을 제공한다.
- 청혼 화면에는 클릭 가능한 답변 버튼이 없다.
- 마지막 문구 후 최소 2초의 정적이 유지된다.
- 모바일 세로 화면에서 텍스트와 사진이 잘리지 않는다.
